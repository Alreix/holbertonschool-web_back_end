# holbertonschool-web_back_end

This repository contains projects completed as part of the Holberton School Web Back-End curriculum.

The goal of this repository is to practice core back-end development concepts using Python, JavaScript, Node.js, MongoDB, and modern ES6 features.  
Each folder focuses on a specific technical topic and contains small exercises designed to build practical understanding step by step.

## Projects

### ES6_basic

This project introduces the basics of modern JavaScript with ES6 syntax.

It contains exercises about:
- constants and block-scoped variables;
- arrow functions;
- default parameters;
- rest parameters;
- spread syntax;
- string interpolation;
- object property shorthand;
- loops and object creation.

### ES6_classes

This project focuses on object-oriented programming in JavaScript using ES6 classes.

It contains exercises about:
- creating classes;
- constructors;
- getters and setters;
- class methods;
- inheritance;
- static methods;
- class extension;
- object behavior and validation.

### ES6_data_manipulation

This project focuses on manipulating data structures in JavaScript.

It contains exercises about:
- arrays of objects;
- `map`;
- `filter`;
- `reduce`;
- typed arrays;
- sets;
- maps;
- updating values inside collections;
- extracting and transforming data.

### ES6_promise

This project introduces asynchronous programming in JavaScript using Promises.

It contains exercises about:
- creating promises;
- resolving and rejecting promises;
- using `.then()`, `.catch()` and `.finally()`;
- handling errors;
- using `Promise.all`;
- async/await;
- managing multiple asynchronous operations.

### Node_JS_basic

This project introduces the basics of Node.js and server-side JavaScript.

It contains exercises about:
- printing messages with Node.js;
- reading from standard input;
- reading files synchronously and asynchronously;
- creating basic HTTP servers;
- using Express.js;
- creating routes;
- organizing a simple server structure.

### NoSQL

This project introduces NoSQL databases using MongoDB.

It contains exercises about:
- listing databases;
- creating or using a database;
- inserting documents;
- finding documents;
- counting documents;
- updating documents;
- deleting documents;
- using Python with MongoDB;
- filtering data by topics;
- analyzing logs stored in MongoDB.

### pagination

This project focuses on pagination techniques in Python.

It contains exercises about:
- calculating page indexes;
- simple pagination;
- hypermedia pagination;
- deletion-resilient pagination;
- returning paginated data with useful metadata.

### python_variable_annotations

This project introduces type annotations in Python.

It contains exercises about:
- typing function parameters;
- typing return values;
- typing variables;
- using basic types such as `int`, `float`, `str`, and `bool`;
- typing lists, tuples, and callable functions;
- making Python code clearer and easier to understand.

### python_async_function

This project introduces asynchronous programming in Python.

It contains exercises about:
- async functions;
- `await`;
- coroutines;
- running multiple coroutines concurrently;
- measuring runtime;
- creating asyncio tasks.

### python_async_comprehension

This project focuses on asynchronous comprehensions and generators in Python.

It contains exercises about:
- async generators;
- async comprehensions;
- collecting asynchronous results;
- measuring execution time for async operations.
